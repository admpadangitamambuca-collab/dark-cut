# DarkCut AI

Sistema de cortes automáticos para vídeos e lives com títulos, hashtags e downloads em formato vertical (9:16) e horizontal (16:9). Sem publicação automática.

## Arquitetura prevista
- Frontend hospedado no Netlify
- Worker Python hospedado no Render para análise e processamento
- GitHub como repositório central do código-fonte

## Situação
Repositório preparado para receber a versão DarkCut AI v2.2. **O código-fonte existente ainda não foi importado**, portanto este repositório não deve ser considerado uma versão funcional.
